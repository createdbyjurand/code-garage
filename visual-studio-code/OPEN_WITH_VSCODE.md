# Menu kontekstowe "Open with Code" w Windows 10

```bash

# Pliki

User: Computer\HKEY_CURRENT_USER\Software\Classes\*\shell\VSCode
System: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Classes\*\shell\VSCode

# Katalogi (PPM na folderze)

User: Computer\HKEY_CURRENT_USER\Software\Classes\Directory\shell\VSCode
System: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Classes\Directory\shell\VSCode

# Tło katalogu (PPM na pustym miejscu w folderze)

User: Computer\HKEY_CURRENT_USER\Software\Classes\Directory\Background\shell\VSCode
System: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Classes\Directory\Background\shell\VSCode

```
